02

Latar Belakang

  • Barang hilang sering hanya diumumkan lewat grup chat kelas
  • Pengumuman cepat tenggelam dan tidak terpusat
  • Tidak ada verifikasi kepemilikan, rawan salah serah
  • Butuh satu tempat: lapor temuan, cari barang, klaim, chat, serah terima
03

Solusi: LaporBarang

Satu tempat untuk melaporkan barang temuan, mencari barang hilang, dan mengklaimnya dengan aman.

  1. Penemu melaporUnggah foto, judul, kategori, lokasi, dan tanggal temuan.
  2. Pemilik mencariCari dan filter barang temuan, tanpa perlu login.
  3. Klaim dengan ciri-ciriPemilik menyebut detail barang, lalu chat dengan penemu.
  4. Serah terimaPenemu setuju, serah terima dikonfirmasi, status barang selesai.
04

Tujuan & Manfaat

  • Mempercepat barang temuan kembali ke pemilik
  • Mengurangi kehilangan barang berharga siswa
  • Melatih siswa tertib administrasi dan jujur
  • Membantu guru dan BK punya data barang hilang
05

Fitur Utama

  • Daftar akun dengan foto profil
  • Laporkan temuan: judul, kategori, deskripsi, lokasi, tanggal, foto
  • Cari dan filter barang temuan
  • Klaim dengan validasi ciri-ciri
  • Chat penemu dan pengklaim
  • Panel admin: kelola akun siswa dan pantau semua klaim
  • Publik

    Beranda + statistik, semua barang, detail barang, cara pakai

  • Siswa

    Login lalu dashboard, lapor temuan, klaim & chat, profil

  • Admin

    Kelola akun siswa, pantau semua klaim

12

Responsif di HP

  • Tata letak menyesuaikan layar HP
  • Menu samping bisa dibuka dan ditutup
  • Semua fitur tetap bisa dipakai dari HP
13

Alur Klaim & Serah Terima

  1. Barang tersediaStatus available. Siapa pun yang login boleh mengajukan klaim.
  2. Klaim masukPemilik menulis ciri-ciri barang. Klaim berstatus pending, barang belum berubah.
  3. Penemu memutuskanTerima: klaim approved, barang in_process. Tolak: klaim rejected, barang kembali available.
  4. Serah terimaKonfirmasi mengubah klaim dan barang menjadi completed.
available pending approved in_process completed rejected
14

Teknologi

Backend

Laravel, PHP, Eloquent

Laravel 13, PHP 8.3+, Eloquent ORM untuk seluruh logika aplikasi.

Frontend

Blade & CSS custom

Blade, CSS custom, dan JavaScript vanilla tanpa framework berat.

Database

MySQL

Empat tabel utama: users, items, claims, messages.

Server

php artisan serve

Symlink storage untuk menyajikan foto barang.

15

Kendala & Solusi

  • Foto barang tidak tampil karena public/storage bukan symlink
  • Solusi: hapus folder kosong lalu jalankan php artisan storage:link
  • URL foto dibuat mengikuti domain aplikasi supaya tidak salah alamat
  • Ditambah automated test agar masalah tidak terulang
16
